Envie para a nuvem sem abrir o navegador.

Um widget gratuito no canto da tela do Windows. Solte arquivos ou pastas nele e eles vão direto para o Google Drive, o OneDrive ou o Dropbox, com o link pronto para compartilhar. Sem cadastro e com código aberto.

Baixar para Windows Windows 10 e 11, 64 bits. Versão para processadores ARM

Na primeira vez, o navegador e o Windows podem avisar que não reconhecem o instalador. Veja como continuar.

    Abra ou compartilhe

    Quando termina, um aviso do Windows confirma o envio. Abrir leva ao arquivo na nuvem, e Copiar link gera um link para mandar a quem quiser.

O que o Boxe Zone acessa

  • Google Drive

    Só os arquivos e pastas que o próprio Boxe Zone criou. O resto do seu Drive fica fora do alcance do app.

  • OneDrive

    Permissão para criar pastas e enviar arquivos no seu OneDrive, que é o que o envio precisa.

  • Dropbox

    Permissão para enviar arquivos, criar o link quando você clica em Copiar link e ler o e-mail da conta, que aparece no app para você saber qual conta está ligada.

Os arquivos vão do seu computador direto para o serviço que você escolheu. O acesso fica guardado no seu computador, criptografado pelo Windows. Os detalhes estão na política de privacidade.

Sobre o instalador

O instalador não tem assinatura digital. Por isso, na primeira vez, o navegador e o Windows podem avisar que não reconhecem o arquivo. É só confirmar:

  1. No Edge, se o download disser que o arquivo "normalmente não é baixado", clique em ⋯ e depois em Manter.
  2. Em "Verifique se você confia…", clique na seta ao lado de Excluir e em Manter mesmo assim.
  3. Ao abrir o instalador, se aparecer "O Windows protegeu o computador", clique em Mais informações e depois em Executar assim mesmo.

O Boxe Zone é código aberto (licença MIT). Cada versão é compilada pelo GitHub Actions a partir do código público deste repositório, e o botão de download baixa o instalador direto da página de Releases do GitHub. Nenhum arquivo passa por outro lugar.
