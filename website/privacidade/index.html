Política de privacidade

Atualizada em 13 de outubro de 2026.

O Boxe Zone não tem servidor e não coleta dados. Os arquivos que você solta no widget vão do seu computador direto para o Google Drive, o OneDrive ou o Dropbox, na conta que você conectou. O acesso a essas contas fica guardado só no seu computador, criptografado pelo Windows.

Quem é o responsável

O Boxe Zone é um aplicativo gratuito para Windows desenvolvido por Lucas Venancio. Dúvidas sobre esta política ou sobre os seus dados: lucasvenanciodev@gmail.com.

O que o app faz

O Boxe Zone é um widget que fica no canto da tela. Você conecta uma ou mais contas de armazenamento e, ao soltar um arquivo na área de um destino, o app envia esse arquivo para a pasta escolhida nessa conta. Ele não lê, analisa nem modifica o conteúdo dos seus arquivos: apenas os envia.

Dados que o app acessa em cada serviço

O login é feito no navegador, na página do próprio serviço. O Boxe Zone nunca vê a sua senha: ele recebe uma autorização de acesso (token) com as permissões abaixo.

Google Drive

  • Permissão drive.file: acesso apenas aos arquivos e pastas que o próprio Boxe Zone criou ou enviou. O app não vê nem altera nenhum outro arquivo do seu Drive.
  • O e-mail da conta, para mostrar no app qual conta está conectada.

OneDrive (Microsoft)

  • Permissão Files.ReadWrite: usada para criar a pasta de destino e enviar os arquivos para o seu OneDrive.
  • Permissões padrão de login da Microsoft (openid, profile e offline_access), que identificam a conta e mantêm você conectado sem pedir a senha a cada envio.
  • O nome de usuário (e-mail) da conta, para mostrar no app qual conta está conectada.

Dropbox

  • Permissão files.content.write: usada para enviar os arquivos para a pasta de destino.
  • Permissão account_info.read: o e-mail da conta, para mostrar no app qual conta está conectada.

O que fica no seu computador

Tudo o que o Boxe Zone guarda fica na pasta %LocalAppData%\BoxeZone do seu usuário do Windows:

  • Autorizações de acesso (tokens) das contas conectadas, criptografadas pelo Windows e legíveis apenas pelo seu usuário. Nunca são gravadas em texto puro nem em registros de erro.
  • Preferências: quais destinos estão ligados, as pastas de destino, o atalho de teclado, o tema e a posição do widget.
  • Registro de erros (crash.log), criado apenas se o app fechar por um erro inesperado. Ele contém o tipo e a mensagem do erro, que podem incluir o nome de um arquivo ou pasta, e nunca contém tokens nem o conteúdo de arquivos. Ele não é enviado para lugar nenhum.

As notificações do Windows mostram o nome do arquivo enviado e ficam na central de notificações do seu computador, como as de qualquer outro app.

O que o app não faz

  • Não envia dados para servidores do Boxe Zone. Não existe servidor do Boxe Zone.
  • Não coleta estatísticas de uso, telemetria nem dados de navegação.
  • Não vende, aluga nem compartilha dados com terceiros. O app se comunica apenas com os serviços que você conectou (Google, Microsoft e Dropbox), para fazer login e enviar os seus arquivos, e com o GitHub, para saber se há versão nova.
  • Não usa os seus dados para publicidade nem para treinar modelos de inteligência artificial.

Verificação de versão nova

No máximo uma vez por dia, enquanto está aberto, o Boxe Zone consulta a página pública de versões do projeto no GitHub para saber se existe uma versão mais nova. O pedido não leva nenhum dado seu: o GitHub recebe apenas o que qualquer acesso a um site recebe, como o endereço IP. Se houver versão nova, o app avisa por uma notificação e nas Configurações; nada é baixado ou instalado sem você.

Essa consulta pode ser desligada na instalação (opção "Verificar versões novas") ou a qualquer momento em Configurações > Verificar versões novas. Desligada, o app não se comunica com nenhum sistema além dos serviços que você conectou. O instalador mostra um resumo desta política antes de instalar.

Uso de dados das APIs do Google

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google pelo Boxe Zone seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado. Os dados do Google são usados apenas para enviar os arquivos que você escolheu e mostrar qual conta está conectada.

Como remover o acesso e os dados

  • No app: em Configurações, clique em Desconectar na conta. No Google Drive e no Dropbox, isso também revoga a autorização no serviço. No OneDrive, a sessão é apagada do seu computador; para revogar também na Microsoft, use o link abaixo.
  • Nos serviços, a qualquer momento:
    • Google: myaccount.google.com/permissions
    • Microsoft: account.live.com/consent/Manage
    • Dropbox: dropbox.com/account/connected_apps
  • No computador: para apagar tudo o que o Boxe Zone guardou, feche o app pelo ícone da bandeja (Sair) e apague a pasta %LocalAppData%\BoxeZone.

Os arquivos que você já enviou continuam na sua conta do serviço, sob o seu controle, como qualquer outro arquivo seu.

Seus direitos

Como o Boxe Zone não coleta nem armazena dados pessoais fora do seu computador, não há dados seus em poder do responsável pelo app para consultar, corrigir ou excluir. Ainda assim, se tiver qualquer pedido relacionado à Lei Geral de Proteção de Dados (LGPD), escreva para lucasvenanciodev@gmail.com.

Mudanças nesta política

Se o que o app acessa ou guarda mudar, esta página será atualizada antes da nova versão ser publicada, com a data de atualização no topo.
